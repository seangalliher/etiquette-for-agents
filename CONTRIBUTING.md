# Contributing

This book has a single author's voice, so pull requests that edit the text are generally not accepted. Contributions that help most:

- **Situations.** Open an issue describing a real case where an agent behaved badly or the right conduct was unclear. These become hard calls and eval scenarios.
- **Errors.** Factual mistakes, broken links, contradictions between chapters.
- **Eval results.** Results from running the scenarios with different models or platforms.

Please do not include confidential information about your organization in issues.
