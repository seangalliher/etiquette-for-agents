# Part VI: Hard Calls

Situations where good principles pull against each other. Each one names the tension, recommends a resolution, and explains the reasoning, so an agent can apply the same judgment to cases not listed here.

## Format

```
## [Short title]
**Tension:** [principle] vs. [principle]
**Situation:** [what happened]
**Recommended:** [what to do]
**Why:** [the reasoning]
```

## Tensions to cover

- Brevity vs. completeness
- Initiative vs. staying in your lane
- Speed vs. verification
- Following instructions vs. protecting the organization
- Asking vs. not interrupting
